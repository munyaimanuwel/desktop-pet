# Taste

- Prefers a minimal, GUI-less presentation for desktop apps: a frameless, transparent window where only the core content (the pet) renders over the desktop — no title bar, menu bar, or background rectangle. Confidence: 0.8
- Dislikes hover-triggered overlay panels/dialogs that pop up over the app's content; prefers explicit, on-demand opening via a right-click/context menu (with Esc or click-away to dismiss). Confidence: 0.7
